# Shoes Inventory Management System

A web-based Shoes Inventory Management System developed using HTML, CSS, PHP and MySQL.

## Technologies Used
- HTML
- CSS
- PHP
- MySQL
- XAMPP

## Features
- Add shoe details
- View shoe inventory
- Manage shoe records
- Contact page

## Installation

1. Install XAMPP.
2. Copy the project folder into `htdocs`.
3. Start Apache and MySQL.
4. Open phpMyAdmin.
5. Create a database named `shoes_db`.
6. Import the project database SQL file.
7. Configure `db.php` using your local database settings.
8. Open `http://localhost/your-project-folder/` in your browser.

## Database Configuration

Use `db.example.php` as a reference to configure your local `db.php`.
